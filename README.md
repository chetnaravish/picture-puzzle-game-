##  About the Project

Picture Puzzle is a fun and challenging browser game where players arrange puzzle pieces to complete a picture. As the player moves ahead, the levels get harder, the timer keeps the game exciting, and coins are earned for every completed level.

This project was created through **vibe coding**, using Google AI Studio and smart prompts to turn an idea into a working game.

##  Features

-  **Increasing Difficulty:** The puzzle gets harder as the player moves to higher levels
-  **Timer:** Every level has a timer, so the player has to solve the puzzle before time runs out
-  **Two Types of Hints:**
  - **View Full Image:** Shows the complete picture again, so the player can remember the correct arrangement
  - **Auto-Place a Piece:** Automatically puts one puzzle piece into its correct box
-  **Coin Rewards:** Players collect coins every time they complete a level
-  **Browser Based:** Works on mobile and desktop, with no installation needed

## How to Play

1. Open the game: [picturepuzzle.ai.studio](https://picturepuzzle.ai.studio/)
2. Arrange the puzzle pieces to complete the picture before the timer ends.
3. Stuck? Use a hint to view the full image again, or let the game place one piece for you.
4. Complete the level to collect coins and move on to a harder one.
